# Final Report

## Motivation
To demonstrate the practical application of Chapter 12: Composite Surfaces by building an interactive tool that bridges the gap between mathematical theory (B-spline approximation) and visual results.

## Implementation Details
The core was implemented in TypeScript without external math libraries to ensure complete control over the linear algebra pipeline. The Gaussian Elimination solver handles the Normal Equations generated by the Least Squares formulation. The tensor product surface is constructed via the separable method, converting $O((NM)^3)$ complexity into manageable sequential $O(N^3)$ operations suitable for client-side execution.

## Discussion
The application successfully demonstrates that a surface is a "family of curves". By adjusting the control points count, users can visibly see the transition from loose approximation (stiff surface) to tight fitting (wobbly surface if data is noisy). The visuals confirm that the B-spline surface smooths the input stack.
