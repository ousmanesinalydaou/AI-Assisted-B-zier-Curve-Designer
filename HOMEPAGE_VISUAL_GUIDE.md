# 🎨 Homepage Visual Guide

## How to Access

1. **Start the development server**:
   ```powershell
   npm run dev
   ```

2. **Open your browser**:
   - Homepage: `http://localhost:5173/`
   - Main App: `http://localhost:5173/app`

## 🎨 Interactive Features

### **Navbar**
- Click logo → Go to homepage
- Click "Home", "About", "Docs", "Report" → Smooth scroll to section
- Click "Launch App" → Navigate to `/app`
- Click moon/sun icon → Toggle dark/light theme
- Mobile: Hamburger menu → Dropdown navigation

### **Hero Section**
- Bézier curve SVG animates on load (path drawing effect)
- Gradient orbs pulse behind logo
- "Launch Application" button → Routes to `/app`
- "View Documentation" button → Scrolls to docs section
- Technology pills fade in one by one

### **Background Animation**
- 5 Bézier curves moving independently
- Each curve has 4 control points
- Control points bounce off screen edges
- Control polygons shown with dashed lines
- Smooth, subtle, non-distracting

### **Features Section**
- Cards scale up on hover
- Shadow intensifies on hover
- Icon boxes have gradient backgrounds
- Smooth reveal as you scroll

### **Documentation**
- Search bar filters in real-time
- Category buttons highlight when active
- Click any doc card → Opens modal
- Modal shows:
  - Full markdown content
  - Syntax-highlighted code blocks
  - Tables, lists, headings
  - Close button or click outside to dismiss

### **Report Section**
- "View" buttons open PDF in new tab
- "Download" buttons download the file
- Embedded viewer shows first page preview
- Scroll within viewer to read full report

## 📱 Responsive Behavior

### **Desktop (> 1024px)**
- Navigation: Horizontal bar
- Features: 2x2 grid
- Docs: 3 columns
- Reports: 2 columns side-by-side

### **Tablet (640px - 1024px)**
- Navigation: Horizontal bar (condensed)
- Features: 2 columns
- Docs: 2 columns
- Reports: 2 columns

### **Mobile (< 640px)**
- Navigation: Hamburger menu
- Features: 1 column (stacked)
- Docs: 1 column
- Reports: 1 column (stacked)
- All text sizes scale down
- Touch targets enlarged (44px minimum)

## 🌙 Theme Toggle

### **Dark Theme**
- Background: Dark gray (#1a1a1a, #0a0a0a)
- Text: White, light gray
- Cards: Dark with subtle borders
- Animations: Purple/cyan glows

### **Light Theme**
- Background: White, light gray (#f9fafb)
- Text: Dark gray, black
- Cards: White with shadows
- Animations: Softer colors

**Theme persists** between homepage and app via Zustand store!

## ⌨️ Keyboard Shortcuts

On homepage:
- **Escape** → Close modals
- **Tab** → Navigate elements
- **Enter** → Activate buttons/links

In main app (`/app`):
- All original shortcuts still work!
- **T** → Toggle theme
- **V** → Toggle select/draw mode
- **Ctrl+S** → Save project
- (See app for full list)
